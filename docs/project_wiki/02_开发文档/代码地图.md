# 代码地图（0.5.1）

## 模块职责

| 文件 | 主要入口/职责 |
|------|---------------|
| `src/common.js` | 数据目录、路径常量、日志、JSON 读取、原子写与文件锁 |
| `src/settings.js` | `loadSettings`、规则读取/校验/编译、提示词与快速通道加载；CLI 与加载端共享规则校验约束 |
| `src/provider.js` | `resolveProvider`、`callLlm`：只读专用渠道，OpenAI/Anthropic 请求、超时及重试 |
| `src/reviewer.js` | `reviewToolUse`：接管条件、规则优先级、保守参数校验、脚本边界、脱敏、总预算、缓存与模型裁决 |
| `src/decision.js` | `emitDecision` 输出标准 hookSpecificOutput；`emitCrash` 阻断退出 |
| `src/hook_main.js` | stdin 协议检查、调用 reviewer、输出决策；无插件 UI 映射 |
| `src/ctl.js` | init/status/set、rules、prompt、provider；校验与写入错误 exit 1 |

## reviewer 定位

- 规则：`matchDangerRules` / `matchCompoundRules`。固定 `ask > deny（提示）> allow`，全文 allow 不能直接覆盖复合命令；deny 提示不得被本地捷径遮蔽。
- 解析：`splitTopLevelCommands`。有限 shell 语法辅助解析，不保证解析任意 shell；自动 allow 必须另行保守校验结构和参数。
- 脚本：`extractScriptRefs` / `collectScriptAttachments`。cwd 边界、普通文件、链接、敏感路径组件、数量及读取限制；必要内容不完整或 truncated 时转 ask。
- 载荷：`buildReviewPayload`。先脱敏原始字段再序列化，工具、附件、上下文及规则提示共用一个 max_payload_chars，不能独立追加预算。
- 缓存：`computeCacheKey` / `reviewCacheKey` / `readCachedDecision` / `writeCachedDecision`。策略摘要、cwd、输入、附件摘要参与键；严格检查条目结构、有限 expires 与到期状态，不兼容性信任旧条目。
- 模型：`parseVerdict` / `formatVerdictReason`。模型 allow/deny，模型 ask 收敛 deny；故障或必要输入不足 ask；ask/deny 通过 additionalContext 向主 agent 补充原因。

函数的具体参数以源码为准，安全修复期间不把内部签名当稳定公共 API。

## 配置与规则

`settings.js` 的 `validateDangerRule` 被 CLI 与加载端复用；规则数量、pattern 与描述长度均有上限。危险规则整表超限不能简单截去尾部（可能丢失后置 ask），应保守转人工；快速通道超限应停用捷径。CLI 拒绝不合法写入，不报告“成功但运行时忽略”。

## 接口与验证

hook 输出为 `hookSpecificOutput` 内的 `hookEventName`、`permissionDecision`、`permissionDecisionReason` 和可选 `additionalContext`；pass 空输出，崩溃 exit 2。不再提供 simple 输出切换、dialog/gui 模块或插件 session 命令。

`hooks/hooks.json` 注册 Bash/Write/Edit/ApplyPatch，timeoutMs 为 120000。运行 `npm test` 执行离线验证；不要用实际危险命令验收。
