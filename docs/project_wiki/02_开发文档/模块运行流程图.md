# 模块运行流程图

## 一次命令审查的完整时序（含对话框裁决）

```mermaid
sequenceDiagram
    participant M as 主 agent
    participant Z as ZCode 客户端
    participant H as node hook_main.js
    participant R as reviewer.js
    participant P as provider.js
    participant L as LLM(安全子agent)
    participant U as 用户(审查对话框)

    M->>Z: 发起 Bash 工具调用
    Z->>H: PreToolUse(stdin JSON)
    H->>R: reviewToolUse(input)
    R->>R: ①开关②工具过滤③全文规则③'复合逐段
    alt 规则/复合层直接决策
        R-->>H: allow(白名单) / ask(确认门槛) + 规则描述
        Note over R: deny 命中不拦截——提炼 ruleHint 风险提示随载荷送审
    else 未命中或带 ruleHint
        R->>R: ③''快速通道④会话白名单(带 hint 时均跳过)④.5脚本内容附加(inspect_scripts)
        R->>R: ⑤缓存查询(键含附件摘要)
        alt 缓存命中
            R-->>H: 复用决策
        else 未命中
            R->>P: resolveProvider(settings)
            P-->>R: baseURL/apiKey/model
            R->>P: callLlm(提示词+工具JSON+规则提示+可选脚本附件)
            alt LLM 链路失败(未配置/超时/非2xx/输出异常)
                R-->>H: ask 转人工审批(审批模型不可用,绝不自动许可)
            else 正常返回
                P->>L: POST /v1/messages (thinking disabled)
                L-->>P: 结论 JSON
                P-->>R: 文本
                R->>R: 解析+ask存疑收敛deny+写缓存(附件摘要加盐)
            end
        end
    end
    R-->>H: {action, reason}
    alt action=ask 且 dialog_on_ask(默认关,走客户端原生框)
        H->>U: 弹出审查对话框(命令+三段式分析)
        U-->>H: 允许执行 / 本次对话允许 / 拒绝
        Note over H: 允许→改判 allow；本次对话允许→写会话白名单+改判 allow；<br/>拒绝→改判 deny；关窗=拒绝；故障→保持 ask
    end
    H-->>Z: stdout 决策 JSON
    alt allow
        Z-->>M: 直接执行
    else ask(对话框关闭/故障时)
        Z-->>U: 客户端原生审批框
    else deny
        Z-->>M: 拦截并转述原因
    end
```

## 审批渠道解析（专用渠道，唯一 LLM 来源）

```mermaid
flowchart TD
    A["读 ~/.zcode/auto-review/review_provider.json<br/>（下划线前缀键为填写指引，加载时剥离）"] --> B{base_url 与 api_key<br/>填写状态?}
    B -- "全空（未配置模板）" --> P["视为未配置 → ProviderError 上抛<br/>→ 总兜底 ask 转人工审批"]
    B -- "只填一半" --> P2["ProviderError（配置错误提示）上抛<br/>→ 总兜底 ask 转人工审批"]
    B -- "填写完整" --> C{model 已填?}
    C -- 否 --> P3["ProviderError（未填 model）上抛<br/>→ 总兜底 ask 转人工审批"]
    C -- 是 --> D{"kind?<br/>（api_kind 或按 URL /anthropic 推断）"}
    D -- anthropic --> E["POST baseURL + /v1/messages<br/>(thinking disabled, max_tokens 2048)"]
    D -- openai 兼容 --> F["POST baseURL + /chat/completions"]
    E --> G["node:http/https 直连<br/>connection: close + agent: false<br/>（避免 undici 长连接在进程退出时触发 libuv 崩溃）"]
    F --> G
```

> 专用渠道是审批的唯一 LLM 来源，**不回落 ZCode provider 表**（主 agent 渠道多为需客户端签名的
> Coding Plan，直连必败 401/400）。未配置或不可用时错误上抛，由决策管线总兜底转人工审批（ask）——
> 模型不在场绝不自动许可，恢复后相同命令重新进入自动审查。
