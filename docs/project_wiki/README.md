# auto-review 项目 Wiki

> ZCode 自动审批权限插件：上下文干净的安全子 agent 全自动二值裁决权限外的命令——**allow 立即执行，deny 拦截并把风险分析与替代做法回传主 agent 修改重试**，日常全程无人工介入；仅你设置的 ask 确认门槛（如关机）与审批模型不可用时会转你确认。

作者: hh-zyb ｜ 版本: 0.4.0 ｜ 技术栈: Node.js ≥ 18（零第三方依赖）+ PowerShell WinForms GUI + ZCode 插件体系（hooks / commands）

## 功能特性

- **模拟第五种权限模式**：内置自动编辑模式 + PreToolUse hook 门卫，全自动二值裁决（allow/deny）
- **上下文干净的安全子 agent**：只看本次工具调用 JSON（+ 可选脚本附件），不接触对话历史，免疫对话内提示注入
- **低风险命令快速通道**：dir/ls/cat/git status/git add/git commit/mkdir 等 25 类低风险命令 0 次 LLM 调用静默放行
- **专用审批渠道**：审批只认 `~/.zcode/auto-review/review_provider.json`（OpenAI/Anthropic 双协议，瞬时故障重试 1 次）；未配置或不可用时命令转人工审批（绝不自动许可）
- **插件审查对话框**（默认关闭，`dialog_on_ask=true` 时介入 ask 决策：规则确认门槛、模型存疑、模型不可用兜底）：现代化深色窗口（风险徽章/命令卡片/三段式分析），点击即裁决、无超时等待
- **图形配置界面**：`/auto-review gui`，与命令式配置完全等价，全组件统一深色风格；含提示词编辑器
- **危险规则做路由不做终审**：正则先行——allow=白名单快速放行 / ask=转用户确认（恒生效，如出厂的关机确认门槛）/ deny=提炼风险提示送审由审批模型裁决（模型的 deny 才是拒绝）；复合命令逐段审查防白名单绕过
- **脚本内容随命令送审**（默认关闭）：python/node/bash 等调用的脚本文件内容自动附加送审，按实际内容审查
- **可定制审查策略**：提示词在 GUI 编辑器全文显示、就地修改，立即生效
