# auto-review 项目 Wiki

版本：0.6.0 ｜ Node.js ≥ 18 ｜ 零第三方依赖

通过自动编辑模式下的 PreToolUse 与 PermissionRequest 两层 hook 审查工具调用。规则按 `ask > deny（提示送审）> allow` 路由：默认 `ask_policy=model` 下 ask 门槛降级为送审提示、由专用审批模型终审，`user` 策略保持转用户确认。快速放行需要保守的命令结构与参数校验（含安全组合命令逐段判定），其他请求由专用审批模型裁决。审批模型不可用、载荷超限或缺少完整审查输入时转人工审批，不用截断内容取得自动许可。

当前版本只使用客户端原生审批界面，不再提供插件 GUI、插件会话白名单或简化输出协议。上下文隔离、脱敏和有限 shell 解析是风险缓解措施，不是完备安全保证。
