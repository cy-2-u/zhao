# auto-review 项目 Wiki

版本：0.8.2 ｜ Node.js ≥ 18 ｜ 零第三方依赖

通过 PreToolUse 与 PermissionRequest 两层 hook 实现全自动审批（模拟 Codex 全自动模式）：除 plan 与完全访问（yolo）外的所有权限模式自动接管；第二层不设 matcher，客户端任何工具的弹窗请求（含子智能体创建 Agent/Task 与 MCP/扩展工具）都强制送审。规则层只有 deny/allow 两种动作，按 `deny（提示送审）> allow` 路由：deny 只作风险提示、由专用审批模型终审（模型 deny 才是真正的拒绝），allow 是仍需过保守结构与参数校验的白名单候选（含安全组合命令逐段判定）。规则层不存在直接转人工的确认门槛，其他请求由专用审批模型裁决。人工审批是唯一兜底且只由审批模型不可用触发——载荷超限截断、附件不完整照常送模型裁决。网页搜索/抓取等只读工具命中工具级安全白名单即 0 审查直接放行。电源操作（关机/重启等）不在出厂规则内，按普通请求由模型判定是否用户明确要求：明确要求才放行，否则拒绝并要求补充授权依据；取消已排定关机直接放行；模型不可用才进入人工流程。

当前版本只使用客户端原生审批界面，不再提供插件 GUI、插件会话白名单或简化输出协议。上下文隔离、脱敏和有限 shell 解析是风险缓解措施，不是完备安全保证。
