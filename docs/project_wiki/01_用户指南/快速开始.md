# 快速开始（0.5.1）

## 前置条件

- 支持插件与 PreToolUse hooks 的 ZCode 客户端。
- Node.js ≥ 18。零第三方依赖，无需 `npm install`。
- 如需模型审查，准备可信的 OpenAI 或 Anthropic 兼容 API 渠道。

## 安装与开启

1. ZCode 设置 → 插件管理 → 发现 → 添加本地 marketplace，选择含 `marketplace.json` 的项目根目录。
2. 安装并启用 auto-review，确认命令面板出现三个命令。
3. 执行 `/auto-review provider path`，定位或创建 `~/.zcode/auto-review/review_provider.json`。
4. 填写 `base_url`（端点）、`api_key`（密钥）、`api_kind`（openai/anthropic，留空推断）、`model`（模型名）。四项渠道接口不变。
5. 执行 `/auto-review on`，将权限模式切为自动编辑；`/auto-review` 查看状态。

审批只认专用渠道，不回落客户端 provider 表。可选的 `/auto-review provider test` 会真实联网；未配置或故障时，需要模型的请求转客户端人工审批，已满足本地保守放行条件的请求不需要调用模型。

当前版本无插件 GUI 或自建审批窗口；所有 ask 交客户端原生审批。ask 规则仅在插件接管管线时生效。模型 deny 会回传分析与替代做法；模型存疑 ask 收敛为 deny，provider 故障、载荷超限或缺少完整审查输入则 ask。

## 安全验证

在项目根目录离线运行：

```bash
npm test
```

测试使用隔离数据与本地模拟服务，无需真实密钥。不以实际执行危险命令验收，不依据“某命令没弹框”单独判断插件工作正常。查看插件状态与日志，并以当次测试结果为准。

## 数据目录

默认目录为 `~/.zcode/auto-review/`（Windows 为 `C:\Users\<用户>\.zcode\auto-review\`）。

| 文件 | 用途 |
|------|------|
| settings.json | 开关、工具范围、超时、缓存及载荷限制 |
| review_provider.json | base_url / api_key / api_kind / model |
| danger_rules.json | 用户规则，未自定义时使用出厂规则 |
| fast_allow.json | 快速通道候选，仍需参数校验 |
| security_prompt.md | 自定义提示词 |
| cache.json | 具备有效 schema 与 expires 的模型结论缓存 |
| review.log | 决策来源与诊断日志 |

缓存 TTL 取决于配置，0 禁用；不承诺固定一小时。不要上传上述目录的原始内容，脱敏不能覆盖所有 secret。安装目录名 `auto-review-0.5.0` 可保留，版本以清单中的 0.5.1 为准。
