# 快速开始（安装与启用）

## 前置条件

- ZCode 客户端（支持插件与 PreToolUse hooks）
- Node.js ≥ 18（`node --version` 可用即可，无需 npm install——插件零第三方依赖）
- 一个可用的 LLM API 端点（API Key 型，OpenAI 兼容或 Anthropic 兼容均可）——审批专用，
  在 `review_provider.json` 中配置，与主 agent 用什么模型渠道无关

## 一、安装插件（本地 marketplace）

1. 打开 ZCode **设置 → 插件管理**，切到 **发现（Discover）** 标签页；
2. 点 **+** 添加本地 marketplace，选择**本项目根目录**（如 `<项目根目录>`，
   根目录下的 `marketplace.json` 是市场清单——客户端只探测根目录 `marketplace.json`
   或 `.claude-plugin/marketplace.json` 这两个路径）；
3. 在插件列表中找到 **auto-review**，点击 **Get/安装** 并启用；
4. 验证：命令面板输入 `/` 能看到 `/auto-review`、`/danger-rules`、`/security-prompt` 三个命令即安装成功。

## 二、配置专用审批渠道

```
/auto-review provider path      # 定位（首次会创建）~/.zcode/auto-review/review_provider.json
```

在文件里填写 `base_url`（OpenAI/Anthropic 兼容端点）、`api_key`、`model`（推荐快模型），
然后 `/auto-review provider test` 验证连通。审批**只认**这个文件；未配置时 LLM 审查不可用，
命令转人工审批（allow 规则/快速通道照常放行）。

## 三、开启自动审批

```
/auto-review on
```

可视化配置可随时执行 `/auto-review gui` 打开图形设置窗口（开关/规则/策略全在里面）。

然后把 ZCode 权限模式切到**自动编辑模式**（这是自动审批的基座：文件编辑不打扰，命令由安全子 agent 把关）。

> 默认行为说明：**全自动二值裁决**——安全命令 allow 直接执行，危险命令 deny 拦截并把
> 分析与替代做法回传主 agent 修改重试；两类情况转你确认：你设置的 `ask` 规则（如关机）、
> 审批模型不可用时的兜底。想亲自裁决模型存疑可 `/auto-review set ask_to_user true`，
> 想用插件对话框替代客户端审批框可 `/auto-review set dialog_on_ask true`（详见使用指南）。

## 四、验证生效

让主 agent 执行一条普通命令（如 `git status`）：

- **不弹审批框、直接执行** → 门卫已工作（查看审查记录：`~/.zcode/auto-review/review.log`）；
- 主 agent 执行 `rm -rf /` 之类的命令：规则提炼不可逆风险提示送审，由审批模型拒绝并把分析回传。

> 注意：安全子 agent 审查每条命令会引入 1~5 秒延迟。提速靠：低风险命令快速通道（内置
> 25 类，0 延迟）、`/danger-rules add allow '...'` 给高频安全命令加白名单、缓存（默认 1 小时）。
> 审批模型在 review_provider.json 里换成 flash 级快模型也可。

## 数据目录

所有运行时数据在 `~/.zcode/auto-review/`（Windows 即 `C:\Users\<你>\.zcode\auto-review\`）：

| 文件 | 用途 |
|------|------|
| settings.json | 运行时配置（开关、审查工具、超时、缓存等） |
| review_provider.json | 专用审批渠道（base_url/api_key/model，审批唯一 LLM 来源） |
| danger_rules.json | 危险规则表（初始不存在时用出厂 6 条：5 条 deny 送审提示 + 1 条 ask 关机确认） |
| fast_allow.json | 低风险命令快速通道白名单（初始不存在时用出厂 25 条） |
| security_prompt.md | 安全子 agent 提示词（自定义后生成） |
| cache.json | 审查结论缓存 |
| review.log | 审查日志（含每条决策与来源层） |
