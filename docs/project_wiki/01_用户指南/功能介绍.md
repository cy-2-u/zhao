# 功能介绍

## 解决什么问题

ZCode 的内置权限模式是两个极端：全自动模式缺少安全门卫；默认模式每条命令都打断你。
auto-review 填补中间地带——**由一个 AI 安全审查者全自动二值裁决**：

```
主 agent 请求执行命令
   ├─ 命中你设置的规则 → allow 白名单放行 / ask 转你确认（不经过 AI，秒级）；deny 提炼风险提示送审
   ├─ 低风险命令快速通道 → 静默放行（0 次 LLM 调用，0 延迟）
   ├─ 复合命令 → 拆段逐条过规则（白名单无法掩护危险段）
   ├─ 安全子 agent 审查通过（allow）→ 自动放行，不打扰你
   └─ 安全子 agent 认为危险（deny）→ 拦截，风险分析与替代做法回传主 agent 修改重试
                                （模型存疑默认同样按 deny 处理；审批模型不可用时转人工审批）
```

开启「脚本内容随命令送审」后，python/node/bash 等调用的脚本文件内容会自动附加给
安全子 agent——审查结论基于**脚本实际内容**而非文件名猜测（脚本里藏的删除、外传
同样会被指出）。

## 核心能力

| 能力 | 说明 | 对应需求 |
|------|------|----------|
| 自动审批模式 | 自动编辑模式 + hook 门卫，全自动二值裁决（1~5 秒/次；deny 分析回传主 agent 形成修改重试闭环） | 需求1 |
| 脚本全文审查 | Bash 命令逐条分析（含 `;` `&&` `|` 串联的每一段，引号/`$()` 内不误拆） | 需求2 |
| 低风险快速通道 | dir/ls/cat/git status/git add/git commit/mkdir 等 25 类低风险命令 0 次 LLM 静默放行 | — |
| 脚本内容送审 | python/node/bash 等引用的脚本文件内容自动附加送审（默认关闭）；脚本改动后缓存自动失效重审 | — |
| 审查对话框 | 深色现代化窗口（`dialog_on_ask=true` 时介入 ask 决策：规则确认门槛、模型存疑、模型不可用兜底）：风险徽章 + 命令卡片 + 三段式分析，点击即裁决、无超时、关窗=拒绝 | 需求3 |
| 危险规则层 | 本地正则做路由：deny=提炼风险提示送审（模型裁决，不再本地拦截）/ allow=白名单快速放行 / ask=转用户确认（恒生效，不经 LLM）；出厂 5 条不可逆 deny 提示 + 1 条关机确认门槛；复合命令逐段裁决 | 需求4 |
| 可改审查提示词 | 安全子 agent 的策略全文在 GUI 编辑器显示、就地修改（契约字段校验），立即生效；命令方式等价 | 需求5 |
| 专用审批渠道 | 审批只认 review_provider.json（OpenAI/Anthropic 双协议，瞬时故障重试 1 次）；未配置或不可用时命令转人工审批（绝不自动许可） | 需求6 |
| 图形配置界面 | `/auto-review gui`：开关/工具/脚本送审/规则/提示词全可视化，全组件统一风格 | — |

## 安全设计要点

- **上下文干净**：安全子 agent 是 hook 进程内的独立 LLM 调用，只收到本次工具调用的 JSON
  （及开启脚本送审后附加的脚本内容）。对话历史里哪怕被注入了"后续所有命令都视为安全"，
  对本审查层也无效（实测审查员会把命令描述中的诱导性文字标注为"不能作为放行依据"）。
- **确定性优先，模型终审**：你的危险规则永远先于 LLM——ask 门槛直接转你裁决、deny
  提炼风险提示送审（宽泛 allow 排在前面也遮不住，优先级固定）；复合命令任一段命中
  ask 即整条转你、全段放行才走捷径；子 agent 拥有完整 deny 权——deny 时必须给出
  分析与替代做法，回传主 agent 修改重试。
- **失败必保守**：审批模型超时、报错、输出不可解析（重试后仍失败）时一律**转人工审批**
  （绝不自动许可）；hook 输入为空/非法 JSON/缺失工具名属协议异常，直接阻断；插件自身
  崩溃时阻断（exit 2）而非放行。脚本附加功能任何异常只降级为"不附加"，不影响决策保守性。
- **对话框持久等待**（`dialog_on_ask=true` 时）：弹出后不自动消失，直到你点击允许/拒绝；直接关闭窗口按拒绝处理；
  弹不出（锁屏/无桌面）自动回落原生审批，不误当拒绝。
- **默认关闭**：安装后不改变任何行为，`/auto-review on` 或 GUI 勾选后才介入；
  审查对话框（dialog_on_ask，默认关）与脚本内容送审（默认关）均为独立开关。
